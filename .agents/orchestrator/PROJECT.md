# Project: Math Research Catalog Generation

## Architecture
- 10 topic directories under `topics/` containing markdown files of math research problems.
- Master index file `INDEX.md` generated by `gen_index.sh`.
- Programmatic generation tool: `tools/generate_catalog.py` (needs to be configured and run).

## Interface Contracts
- Math pages must strictly adhere to the 10-section layout in `TEMPLATE.md`.
- Frontmatter must be properly populated.
- References must be real, math characters must be escaped.
