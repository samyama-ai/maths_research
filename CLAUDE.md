# CLAUDE.md — Maths Research catalog

## What this repo is
A catalog of open and hard research problems in mathematics, with each problem documented in its own Markdown file following `TEMPLATE.md`, grouped under `topics/<NN-topic-slug>/`. The master topic listing is `TAXONOMY.md`.

## Conventions
- **One problem = one file.** The filename must be the problem slug in `kebab-case.md`.
- **YAML provenance frontmatter** is required at the top of every file:
  * `id`: Stable identity across iterations (format: `NN-topic-slug/problem-slug`). Never change this once assigned.
  * `title`: Double-quoted string of the problem/conjecture name.
  * `topic`: Directory name (`NN-topic-slug`).
  * `status`: `open`, `partially-solved`, `solved-recently`, or `empirically-supported`.
  * `first_added`, `last_reviewed`, `last_substantive_update`: `YYYY-MM`.
  * `provenance`: `synthesized` or `verified`.
- Every problem page must contain all 10 sections from `TEMPLATE.md` in order.
- **Strict citation guidelines**: References must be real. Do not fabricate DOIs, arXiv IDs, or links. If a URL is uncertain, cite the metadata (authors, title, publisher, year) without the link.
- **LaTeX Math Support**: Use standard LaTeX syntax for math. Inline math goes in `$ ... $`, and block equations go in `$$ ... $$`.
- **Escaping inside Math**: Any `#` inside LaTeX math blocks must be escaped as `\\#` to prevent parsing issues on platforms like GitHub (which strips one backslash before rendering).

## Adding a topic or problem
1. Create or navigate to the topic directory under `topics/` (e.g., `topics/01-number-theory/`).
2. If it's a new topic, create a `README.md` file inside that directory outlining the topic scope and an index of problems.
3. Copy `TEMPLATE.md` to create the new problem file (e.g., `topics/01-number-theory/riemann-hypothesis.md`).
4. Update `TAXONOMY.md` if any topic's scope or structure shifts.
5. Regenerate `INDEX.md` by running the indexing script:
   ```bash
   ./gen_index.sh
   ```

## Build & Maintenance
- `INDEX.md` is generated by walking `topics/*/*.md` files. Run `./gen_index.sh` after additions or updates.
