# Katětov's Order Problem for Ideals

> **Topic:** Mathematical Logic & Set Theory · **ID:** `08-logic-set-theory/katetov-order-problem-ideals` · **Status:** open

## 1. Problem Statement / Conjecture

Katětov's order $\leq_K$ compares ideals on countable sets: $\mathcal I\leq_K\mathcal J$ iff there is a map $f$ from the underlying set of $\mathcal J$ to that of $\mathcal I$ pulling every $\mathcal I$-small set back to a $\mathcal J$-small set. The **Katětov order problem** is to describe the structure of $(\{\text{Borel ideals on }\omega\},\leq_K)$.

Concretely, the following are open:

1. **Classification.** Is there a list of *critical* Borel ideals $\mathcal C_1,\dots$ such that for every Borel ideal $\mathcal I$, membership in each natural combinatorial class (tall, P-ideal, weakly Ramsey, Cohen-/random-indestructible, …) is decided by which $\mathcal C_i$ satisfy $\mathcal C_i\leq_K\mathcal I\restriction X$ for some $X\in\mathcal I^+$?
2. **Dichotomies.** Hrušák's *Category Dichotomy* and *Measure Dichotomy*: every Borel ideal is either Katětov-below $\mathrm{nwd}$ (resp. below the trace ideal $\mathrm{tr}(\mathcal N)$), or is Katětov-above a fixed critical ideal on some positive set. Both are theorems for restricted definable classes and conjectures in general (see [Hrušák 2017] for the exact forms and the classes covered).
3. **Complexity and absoluteness.** The relation $\mathcal I\leq_K\mathcal J$ for Borel $\mathcal I,\mathcal J$ is $\Sigma^1_2$ in the codes. Is it $\Sigma^1_2$-complete? Is it absolute between models of $\mathsf{ZFC}$ — can forcing create a Katětov reduction between two Borel ideals where none existed?

A complete solution means either an explicit structure theorem (with proofs of the dichotomies) or independence results showing no absolute classification exists.

## 2. Mathematical Foundations

An **ideal** $\mathcal I$ on a countable set $X$ is a family $\mathcal I\subseteq\mathcal P(X)$ closed under subsets and finite unions, containing $\mathrm{Fin}=[X]^{<\omega}$ and with $X\notin\mathcal I$. Identifying $\mathcal P(X)$ with the Cantor space $2^{X}$, one speaks of **Borel**, $F_\sigma$, analytic ideals. Write
$$\mathcal I^+=\{A\subseteq X: A\notin\mathcal I\},\qquad \mathcal I\restriction A=\{B\cap A: B\in\mathcal I\}\ (A\in\mathcal I^+),\qquad \mathcal I^*=\{X\setminus A: A\in\mathcal I\}.$$

**Katětov order** (Katětov 1968). For ideals $\mathcal I$ on $X$, $\mathcal J$ on $Y$:
$$\mathcal I\leq_K\mathcal J\iff \exists f:Y\to X\ \ \forall A\in\mathcal I\ \ f^{-1}[A]\in\mathcal J .$$
The **Katětov–Blass order** $\leq_{KB}$ requires $f$ finite-to-one. Both are quasi-orders, not partial orders: $\mathcal I\leq_K\mathcal J\leq_K\mathcal I$ does not imply isomorphism.

**Benchmark ideals.**
- $\mathrm{Fin}$; $\mathrm{Fin}\times\mathrm{Fin}=\{A\subseteq\omega^2:\{n:A_n\text{ infinite}\}\in\mathrm{Fin}\}$; $\{\emptyset\}\times\mathrm{Fin}=\{A:\forall n\,A_n\in\mathrm{Fin}\}$.
- $\mathcal{ED}$: on $\omega\times\omega$, generated by vertical lines $\{n\}\times\omega$ and graphs of functions $\omega\to\omega$. $\mathcal{ED}_{\mathrm{fin}}=\mathcal{ED}\restriction\Delta$, $\Delta=\{(n,m):m\leq n\}$.
- $\mathrm{nwd}$: nowhere dense subsets of $\mathbb Q$. $\mathrm{conv}$: subsets of $\mathbb Q\cap[0,1]$ with finitely many accumulation points in $[0,1]$.
- $\mathcal I_{1/n}=\{A\subseteq\omega:\sum_{n\in A}\tfrac1{n+1}<\infty\}$ (summable); $\mathcal Z=\{A:\lim_n \frac{|A\cap n|}{n}=0\}$ (density zero); $\mathrm{tr}(\mathcal N)=\{A\subseteq 2^{<\omega}:\mathcal N\text{-measure of }\{x: \exists^\infty n\, x\restriction n\in A\}=0\}$.
- $\mathcal R$: generated by cliques and independent sets of the random graph on $\omega$.

**Representation theorems.** $\mathcal I$ is $F_\sigma$ iff $\mathcal I=\mathrm{Fin}(\varphi)=\{A:\varphi(A)<\infty\}$ for a lower semicontinuous submeasure $\varphi$ (Mazur 1991). $\mathcal I$ is an analytic P-ideal iff $\mathcal I=\mathrm{Exh}(\varphi)=\{A:\lim_n\varphi(A\setminus n)=0\}$ (Solecki 1999); such ideals are $\Pi^0_3$.

**Katětov characterizations of combinatorial properties.** $\mathcal I$ is *tall* (every infinite set has an infinite subset in $\mathcal I$) iff $\mathcal I\not\leq_K\mathrm{Fin}$. $\mathcal I$ is a P-ideal iff $\mathrm{Fin}\times\mathrm{Fin}\not\leq_K\mathcal I$. For a nonprincipal ultrafilter $\mathcal U$: $\mathcal U$ is a P-point iff $\mathrm{Fin}\times\mathrm{Fin}\not\leq_K\mathcal U^*$; $\mathcal U$ is selective iff $\mathcal{ED}\not\leq_K\mathcal U^*$; $\mathcal U$ is a Q-point iff $\mathcal{ED}_{\mathrm{fin}}\not\leq_K\mathcal U^*$. A MAD family $\mathcal A$ is Cohen-indestructible iff $\mathrm{nwd}\not\leq_K\mathcal I(\mathcal A)\restriction X$ for all $X\in\mathcal I(\mathcal A)^+$, and random-indestructible iff the same holds with $\mathrm{tr}(\mathcal N)$ (Hrušák–García Ferreira 2003). This is the engine of the whole subject: *one* order encodes dozens of properties.

## 3. History & State of the Art (SOTA)

Miroslav Katětov introduced $\leq_K$ in *Products of filters* (1968) and used it in *On descriptive classification of functions* (1972) to calibrate Baire-class problems: the order arose from asking when convergence with respect to one filter can be transported to another. It lay largely dormant until the 1990s–2000s, when Mazur's and Solecki's representation theorems made definable ideals tractable and Hrušák recast a large body of combinatorial set theory in Katětov terms.

Milestones:
- 1968/1972 — Katětov: definition; application to Baire classification and products of filters.
- 1991/1999 — Mazur; Solecki: structure theory for $F_\sigma$ ideals and analytic P-ideals.
- 2003 — Hrušák–García Ferreira: MAD-family destructibility by definable forcings $=$ Katětov position of $\mathcal I(\mathcal A)$ relative to $\mathrm{nwd}$, $\mathrm{tr}(\mathcal N)$, $\mathrm{conv}$.
- 2009–2011 — Meza-Alcántara's thesis and Hrušák's survey: the "Katětov diagram" of critical Borel ideals; Category/Measure Dichotomies proved for low-complexity classes.
- 2017 — Hrušák, *Katětov order on Borel ideals*: the definitive problem list.
- 2020 — Grebík–Hrušák: **no minimal tall Borel ideal** in $\leq_K$, settling a central question negatively.

## 4. Partial Results / Verified Cases

- **$F_\sigma$ and analytic P-ideals.** Katětov position is computable from the submeasure representation; e.g. $\mathcal I_{1/n}\leq_K\mathcal Z$ (identity, since summable $\Rightarrow$ density zero) and $\mathcal Z\not\leq_{KB}\mathcal I_{1/n}$.
- **Low Borel complexity.** The Category Dichotomy is a theorem for ideals of low rank in the Borel hierarchy (through the $\Pi^0_4$/$F_{\sigma\delta\sigma}$ range in the cases treated in [Hrušák 2017]); the general Borel case is open.
- **Closed/compactly generated ideals.** For ideals generated by closed sets, $\leq_K$-comparisons reduce to forcing properties of the associated $\sigma$-ideal quotients (Sabok–Zapletal 2011), giving complete answers for that class.
- **Minimality.** No tall Borel ideal is $\leq_K$-minimal (Grebík–Hrušák 2020); previously each of $\mathrm{nwd}$, $\mathrm{conv}$, $\mathcal{ED}$, $\mathcal R$, $\mathcal Z$, $\mathcal I_{1/n}$ had been shown non-minimal individually.
- **Specific ideals.** Comparisons among the Hindman ideal $\mathcal H$, the Ramsey ideal, and summable ideals are settled in Filipów–Kowitz–Kwela (2023); $\mathcal{ED}_{\mathrm{fin}}\leq_K\mathcal{ED}$ (restriction map) and $\mathcal{ED}\not\leq_K\mathcal{ED}_{\mathrm{fin}}$.
- **Maximal ideals.** For duals of ultrafilters, the P-point / Q-point / selective characterizations of §2 are complete and classical.

## 5. Principal Obstacles

- **No canonical witnesses.** A reduction is an arbitrary function $f:\omega\to\omega$; there is no normal form. Proving $\mathcal I\not\leq_K\mathcal J$ requires diagonalizing against $\mathfrak c$-many maps, and the standard tools (Ramsey-type canonization, Solecki's submeasure calculus) apply only when $f$ can be assumed monotone or finite-to-one — i.e. to $\leq_{KB}$, not $\leq_K$.
- **Descriptive-set-theoretic ceiling.** $\leq_K$ is $\Sigma^1_2$, one quantifier above the analytic level where effective dichotomy machinery ($G_0$, Kechris–Solecki–Todorcevic; Hjorth–Kechris turbulence) works. Existing dichotomy theorems for analytic equivalence relations do not directly apply to a $\Sigma^1_2$ quasi-order.
- **Non-absoluteness risk.** Because the witness is a real, a forcing extension can in principle supply a reduction absent from $V$. No proof of absoluteness is known, so a purely combinatorial classification may be unattainable.
- **Failure of the P-ideal dichotomy analogue.** Todorcevic's PID gives a clean dichotomy for analytic P-ideals inside $\mathsf{ZFC}$ + forcing axioms, but there is no known counterpart for general Borel ideals; the tall Borel ideals form a $\leq_K$-downward-dense class with no bottom (Grebík–Hrušák), so induction "down the order" has no base.
- **Game approximations are strictly weaker.** The Hrušák–Meza-Alcántara comparison game gives sufficient conditions for $\leq_K$; whether it is determined for Borel ideals — which would collapse the gap — is open.

## 6. The Gap

Proven: the order is understood on $F_\sigma$ ideals, analytic P-ideals, closed-generated ideals, and duals of ultrafilters; the dichotomies hold at low Borel rank; no minimal tall Borel ideal exists.

Missing: a transfer principle from bounded Borel rank to all Borel ideals. Every known dichotomy proof runs an induction on a submeasure or a tree representation of the ideal and consumes one level of the Borel hierarchy per step, so it stalls at $\Pi^0_4$. Crossing the gap requires either (i) a canonization theorem making arbitrary reductions between Borel ideals equivalent to continuous or finite-to-one ones on a positive set, or (ii) a $\Sigma^1_2$-level dichotomy theorem for quasi-orders. Neither exists.

## 8. Future Work

- Prove or refute the Category Dichotomy for all Borel ideals; the Measure Dichotomy is expected to follow the same route with $\mathrm{tr}(\mathcal N)$ in place of $\mathrm{nwd}$.
- Determine whether the comparison game is determined for Borel ideals — a positive answer would give a game-theoretic normal form for reductions.
- Settle absoluteness: does $\mathcal I\leq_K\mathcal J$ (Borel) hold in $V$ whenever it holds in a forcing extension? Under $\mathsf{MA}$ or large cardinals?
- Develop canonization: prove that any Katětov reduction between Borel ideals can be replaced by a continuous one on some $\mathcal J$-positive set.
- Chart the $\leq_K$-position of Ramsey-theoretic ideals (Hindman, polynomial van der Waerden), where the combinatorics is explicit and comparisons are decidable case by case.

## 10. Worked Example / Concrete Special Case

**Claim.** For a nonprincipal ultrafilter $\mathcal U$ on $\omega$: $\mathcal{ED}\leq_K\mathcal U^*$ iff $\mathcal U$ is not selective.

Recall $\mathcal U$ is *selective* iff every $g:\omega\to\omega$ is constant or injective on some $U\in\mathcal U$.

**($\Leftarrow$) Constructing the reduction.** Let $\mathcal U$ be non-selective and fix $g:\omega\to\omega$ that is neither constant nor injective on any member of $\mathcal U$. For $k\in\omega$ let
$$h(k)=\bigl|\{j<k: g(j)=g(k)\}\bigr|,\qquad f(k)=(g(k),h(k))\in\omega\times\omega .$$
So $f$ sends the fiber $g^{-1}(n)$ bijectively onto $\{n\}\times\{0,1,\dots\}$.

Check the two generator types of $\mathcal{ED}$:
- *Vertical line* $A=\{n\}\times\omega$: $f^{-1}[A]=g^{-1}(n)$. If this were in $\mathcal U$, $g$ would be constant on a set in $\mathcal U$ — excluded. So $f^{-1}[A]\in\mathcal U^*$.
- *Graph* $A=\{(n,\varphi(n)):n\in\omega\}$ for $\varphi:\omega\to\omega$: $f^{-1}[A]$ meets each fiber $g^{-1}(n)$ in at most one point, so $g$ is injective on $f^{-1}[A]$. If $f^{-1}[A]\in\mathcal U$, $g$ would be injective on a set in $\mathcal U$ — excluded. So $f^{-1}[A]\in\mathcal U^*$.

Every $A\in\mathcal{ED}$ is contained in a finite union of such generators plus a finite set; $\mathcal U^*$ is an ideal, hence closed under finite unions. Therefore $f^{-1}[A]\in\mathcal U^*$ for all $A\in\mathcal{ED}$, i.e. $\mathcal{ED}\leq_K\mathcal U^*$.

**($\Rightarrow$) The converse.** Suppose $f:\omega\to\omega\times\omega$ witnesses $\mathcal{ED}\leq_K\mathcal U^*$ and let $\mathcal U$ be selective. Write $f=(f_0,f_1)$. Since preimages of vertical lines are in $\mathcal U^*$, $f_0$ is not constant on any set in $\mathcal U$; by selectivity there is $U\in\mathcal U$ with $f_0\restriction U$ injective. Then $f\restriction U$ is injective and $f[U]$ meets each column once, so $f[U]$ is contained in the graph of a function $\varphi$ (defined by $\varphi(f_0(k))=f_1(k)$ for $k\in U$, arbitrary elsewhere). That graph $A$ lies in $\mathcal{ED}$, yet $U\subseteq f^{-1}[A]$, so $f^{-1}[A]\in\mathcal U$ — contradiction.

**Reading.** The single ideal $\mathcal{ED}$ decides selectivity for *every* ultrafilter, with no appeal to $\mathsf{CH}$. The open problem of §1 asks for the analogous finite list of critical ideals deciding every combinatorial property of every Borel ideal — and, per §5, the arbitrary function $f$ above is exactly the object no general technique can currently control.
