# Hilbert's Twelfth Problem

> **Topic:** Number Theory · **ID:** `01-number-theory/hilberts-twelfth-problem` · **Status:** open

## 1. Problem Statement / Conjecture

Hilbert's Twelfth Problem asks for the generalization of the Kronecker–Weber theorem to arbitrary algebraic number fields. Specifically, given an algebraic number field $K$, the problem asks for the explicit construction of analytic functions (analogous to the exponential function for the rational numbers $\mathbb{Q}$, or the modular $j$-function for imaginary quadratic fields) whose special values at designated points generate all finite abelian extensions of $K$. 

A complete solution requires specifying a geometric or analytic framework that yields transcendental functions, and a set of arguments (usually associated with the algebraic structure of $K$) such that adjoining the values of these functions to $K$ yields exactly the maximal abelian extension $K^{\text{ab}}$, or more precisely, the ray class fields of $K$.

## 2. Mathematical Foundations

An **algebraic number field** $K$ is a finite algebraic extension of the rational number field $\mathbb{Q}$. A finite extension $L/K$ is called an **abelian extension** if it is a Galois extension and its Galois group $\text{Gal}(L/K)$ is an abelian group. 

Class field theory dictates that every finite abelian extension of $K$ is contained in a **ray class field**. A ray class field $K(\mathfrak{m})$ modulo a formal product of primes (an integral ideal and infinite places) $\mathfrak{m}$ is a specific finite abelian extension of $K$ uniquely determined by the congruence properties of ideals in $K$. 

The **Kronecker–Weber Theorem** asserts that every finite abelian extension of $\mathbb{Q}$ is contained in a cyclotomic field $\mathbb{Q}(\zeta_m)$. Equivalently, the ray class fields of $\mathbb{Q}$ are generated by the special values of the exponential function:
$$ f(z) = e^{2\pi i z} $$
evaluated at rational points $z = 1/m \in \mathbb{Q}$.

For an imaginary quadratic field $K = \mathbb{Q}(\sqrt{-d})$ for $d>0$, the ray class fields are generated by adjoining the values of the **modular $j$-invariant** $j(\tau)$ and the Weber functions, evaluated at points $\tau \in K \cap \mathbb{H}$ (where $\mathbb{H}$ is the upper half-plane).

Hilbert's 12th Problem asks for the identification of analogous analytic functions $F_1, F_2, \dots$ such that for any field $K$, evaluating $F_i$ at appropriately chosen elements $\alpha \in K$ generates the ray class fields $K(\mathfrak{m})$.

## 3. History & State of the Art (SOTA)

The problem was proposed by David Hilbert in 1900 during his address at the International Congress of Mathematicians in Paris, forming the 12th of his famous 23 problems. It was motivated by Leopold Kronecker's "Jugendtraum" (youthful dream), which successfully handled the case of imaginary quadratic fields using the theory of complex multiplication.

In the 1920s, Teiji Takagi and Emil Artin developed modern Class Field Theory, which classifies all abelian extensions of an arbitrary number field $K$ using the internal arithmetic of $K$ (idèle class groups). However, Class Field Theory is purely existential; it proves the existence of ray class fields but does not explicitly construct them via analytic functions.

In the 1970s, Harold Stark proposed **Stark's Conjectures**, which relate the leading terms of the Taylor expansions of Artin $L$-functions at $s=0$ to algebraic units (Stark units) that generate abelian extensions. This provided a framework for what the generators should look like, even if the analytic functions producing them were unknown.

The most profound modern breakthrough occurred between 2021 and 2023. Samit Dasgupta and Mahesh Kakde proved the Brumer-Stark conjecture for totally real fields and subsequently provided an exact $p$-adic analytic formula for Brumer-Stark units. While Hilbert likely envisioned complex-analytic functions, Dasgupta and Kakde's work effectively solves the problem for totally real fields using $p$-adic integration.

## 4. Partial Results / Verified Cases

The conjecture is definitively resolved in the following special cases:
- **$K = \mathbb{Q}$ (The Rational Numbers):** Solved completely by the Kronecker-Weber theorem. The generating function is $e^{2\pi i z}$.
- **$K = \mathbb{Q}(\sqrt{-d})$ (Imaginary Quadratic Fields):** Solved completely via the theory of Complex Multiplication (CM) of elliptic curves.
- **CM Fields (Totally complex quadratic extensions of totally real fields):** Partially solved. The theory of complex multiplication extends to abelian varieties via Shimura varieties. However, unlike elliptic curves, extracting explicit generators for the ray class fields from the moduli of higher-dimensional abelian varieties remains highly computationally complex and not fully explicit.
- **Totally Real Fields (e.g., $K = \mathbb{Q}(\sqrt{d})$ for $d>0$):** Solved in a $p$-adic sense. Dasgupta and Kakde (2023) constructed exact $p$-adic formulas that generate the $p$-parts of the relevant ray class fields.

## 5. Principal Obstacles

The central obstacle for arbitrary number fields (and specifically totally real fields, prior to $p$-adic methods) is the absence of a suitable geometric object. 

For $\mathbb{Q}$, the geometric object is the multiplicative group $\mathbb{G}_m$, which yields the exponential function. For imaginary quadratic fields, the objects are elliptic curves, parameterized by the complex upper half-plane $\mathbb{H}$, yielding the $j$-function.

For a real quadratic field $K = \mathbb{Q}(\sqrt{d})$, there is no natural class of algebraic varieties (like elliptic curves) whose endomorphism rings naturally embed real quadratic orders in a way that generates the required abelian extensions. Classical Hilbert modular forms can be defined over totally real fields, but their special values typically generate extensions of CM fields, not the totally real fields themselves. Traditional complex analytic functions lack the rigid algebraic functional equations necessary to produce algebraic integers when evaluated at algebraic arguments.

## 6. The Gap

The gap between current knowledge and a full resolution of Hilbert's 12th Problem lies primarily in the distinction between $p$-adic analysis and complex analysis. 

While the work of Dasgupta, Kakde, Darmon, and Vonk demonstrates that $p$-adic analytic constructions can successfully produce the required algebraic generators (Stark units and singular moduli) for totally real and real quadratic fields, a classical **complex-analytic** solution remains elusive. It is unknown if there exists a single unifying complex-analytic theory (perhaps involving higher-dimensional transcendental functions, motives, or non-commutative geometry) that handles arbitrary number fields. The exact boundary is therefore extending explicit generative formulas from the $p$-adic topology to the complex topology for non-CM fields.

## 7. Current Research (as of June 2026)

Current research is heavily focused on expanding the $p$-adic successes and attempting to bridge them to complex geometry:
- **Rigid Meromorphic Cocycles:** Henri Darmon and Jan Vonk are actively expanding the theory of rigid meromorphic cocycles to define $p$-adic singular moduli for real quadratic fields, providing a robust analogue to the classical $j$-function.
- **Higher Stark Conjectures:** Generalizing the Brumer-Stark conjecture to higher-rank Stark conjectures, seeking to construct groups of units (rather than single units) using higher-order derivatives of $p$-adic $L$-functions.
- **Equivariant Tamagawa Number Conjecture (ETNC):** Refining the algebraic structural properties of the Stark units using Iwasawa theory.
- *(frontier — verify)*: Recent preprints attempt to lift $p$-adic Stark units to global analytic objects using cohomological frameworks over perfectoid spaces, though this remains heavily scrutinized.

## 8. Future Work

Leading mathematicians have outlined several pathways for future research:
1. **Bridging the Local-Global Divide:** Formulating a geometric theory (potentially using Arakelov geometry or Fargues-Fontaine curves) where both the complex-analytic and $p$-adic analytic Stark units emerge as local manifestations of a singular global geometric object.
2. **Arbitrary Number Fields:** Extending the $p$-adic solutions of totally real fields to arbitrary mixed-signature number fields, where both real and complex infinite places coexist. 
3. **Explicit Computability:** Transforming the $p$-adic integrals of Dasgupta-Kakde into fast polynomial-time algorithms to compute minimal polynomials of generating algebraic numbers, making the theory practically viable for cryptographic or computational number theory applications.

## 10. Worked Example / Concrete Special Case

To understand the core ambition of the problem, consider the base case $K = \mathbb{Q}$. Hilbert's problem demands an analytic function to generate its abelian extensions. 

Let the desired abelian extension be $L = \mathbb{Q}(\sqrt{5})$. This is a Galois extension over $\mathbb{Q}$ with Galois group $\mathbb{Z}/2\mathbb{Z}$, which is abelian.

Using the analytic function $f(z) = e^{2\pi i z}$, we evaluate it at the rational point $z = 1/5$ to obtain the primitive 5th root of unity:
$$ \zeta_5 = e^{2\pi i / 5} $$

Adjoining this special value to $\mathbb{Q}$ gives the cyclotomic field $\mathbb{Q}(\zeta_5)$, which has the abelian Galois group $(\mathbb{Z}/5\mathbb{Z})^\times \cong \mathbb{Z}/4\mathbb{Z}$. 

To see that our target field $L$ is explicitly generated by this evaluation, we take a specific linear combination (a trace) of this special value. Let:
$$ \alpha = \zeta_5 + \zeta_5^{-1} $$
Using Euler's formula, $e^{i\theta} = \cos\theta + i\sin\theta$, we compute:
$$ \alpha = 2 \cos\left(\frac{2\pi}{5}\right) $$
Geometrically, it is a known elementary identity that $\cos(2\pi/5) = \frac{\sqrt{5}-1}{4}$. Therefore:
$$ \alpha = \frac{\sqrt{5}-1}{2} $$
Rearranging this yields:
$$ \sqrt{5} = 2\alpha + 1 $$
Thus, $\sqrt{5} \in \mathbb{Q}(\zeta_5)$, and the abelian extension $\mathbb{Q}(\sqrt{5})$ is completely captured and explicitly constructed using the special value of the exponential function evaluated at $1/5$. Hilbert's 12th Problem asks to find the exact analogue of $f(z)$ for fields other than $\mathbb{Q}$ and $\mathbb{Q}(\sqrt{-d})$.
