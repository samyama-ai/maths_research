# Number Theory

The study of integers, prime numbers, Diophantine equations, and related structures. This field ranges from elementary arithmetic to advanced topics in arithmetic geometry and algebraic number theory.

## Problems Index

* 🔴 [Riemann Hypothesis](./riemann-hypothesis.md) — All non-trivial zeros of the zeta function have real part half.
* 🔴 [Twin Prime Conjecture](./twin-prime-conjecture.md) — There are infinitely many primes that differ by exactly two.
