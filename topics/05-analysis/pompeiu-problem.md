# Pompeiu Problem

> **Topic:** Real & Complex Analysis · **ID:** `05-analysis/pompeiu-problem` · **Status:** open

## 1. Problem Statement / Conjecture

Let $K \subset \mathbb{R}^n$ ($n \ge 2$) be a compact set of positive Lebesgue measure. $K$ has the **Pompeiu property** if the only $f \in C(\mathbb{R}^n)$ satisfying
$$\int_{\sigma(K)} f(x)\,dx = 0 \quad \text{for every rigid motion } \sigma \in M(n)$$
is $f \equiv 0$. Equivalently, the map $f \mapsto \big(\sigma \mapsto \int_{\sigma(K)} f\big)$ is injective on $C(\mathbb{R}^n)$.

**Pompeiu conjecture.** *If $\Omega \subset \mathbb{R}^n$ is a bounded simply connected domain with Lipschitz boundary and $\overline{\Omega}$ fails the Pompeiu property, then $\Omega$ is a ball.*

Balls do fail: rotation invariance plus a zero of a Bessel function kills the integral (Section 10). The conjecture asserts they are the *only* failures among simply connected Lipschitz domains. A complete resolution is either a proof of this statement, or an explicit non-spherical simply connected $\Omega$ and a nonzero $f$ with vanishing means over all congruent copies. The hypotheses matter: without simple connectivity the annulus-type analysis is open, and in non-Euclidean space forms the analogous statement is **false** (Section 4).

## 2. Mathematical Foundations

**Fourier-analytic criterion (Brown–Schreiber–Taylor, 1973).** Let $\chi_K$ be the indicator of $K$ and
$$\widehat{\chi_K}(\xi) \;=\; \int_K e^{-i\langle x,\xi\rangle}\,dx , \qquad \xi \in \mathbb{C}^n ,$$
an entire function of exponential type on $\mathbb{C}^n$ (Paley–Wiener). Then, with $\xi\cdot\xi = \sum \xi_j^2$:
$$K \text{ fails the Pompeiu property} \iff \exists\, \alpha > 0 \ \text{ such that } \ \widehat{\chi_K}(\xi) = 0 \ \ \forall \xi \in \Sigma_\alpha := \{\xi \in \mathbb{C}^n : \xi\cdot\xi = \alpha^2\}.$$
The proof runs through **spectral synthesis** for the $M(n)$-invariant closed subspace of $C(\mathbb{R}^n)$ generated by translates and rotations: such a subspace is generated by its exponential-polynomial elements, and the $M(n)$-irreducible pieces are the eigenspaces $\{u : \Delta u + \alpha^2 u = 0\}$.

**Schiffer's overdetermined problem.** For $\Omega$ bounded with Lipschitz boundary, failing Pompeiu is equivalent (Williams 1976) to the existence of $\alpha>0$ and $u \not\equiv 0$ solving
$$\Delta u + \alpha^2 u = 0 \ \text{ in } \Omega, \qquad u = c \ \text{ (const)} \ \text{ on } \partial\Omega, \qquad \frac{\partial u}{\partial \nu} = 0 \ \text{ on } \partial\Omega .$$
So $\alpha^2$ is a nonzero **Neumann** eigenvalue whose eigenfunction is additionally constant on the boundary. **Schiffer's conjecture:** this forces $\Omega$ to be a ball. (Normalizing $c=0$ gives the equivalent form: $\alpha^2$ is a Dirichlet eigenvalue with $\partial u/\partial\nu \equiv 0$.)

**Serrin-type comparison.** The kindred problem $\Delta u = -1$ in $\Omega$, $u=0$ and $\partial u/\partial\nu = $ const on $\partial\Omega$ forces a ball (Serrin 1971), via the moving-plane method and Weinberger's $P$-function. Schiffer's problem has no maximum principle available because $u$ changes sign for $\alpha^2$ above the first eigenvalue.

**Two-radius theorem (Delsarte).** If $\int_{B(x,r_1)} f = \int_{B(x,r_2)} f = 0$ for all $x$, and $r_1/r_2$ is not a quotient of two zeros of $J_{n/2}$, then $f \equiv 0$. This quantifies exactly how balls fail: a single ball fails, two generic balls do not.

## 3. History & State of the Art (SOTA)

- **1929.** Dimitrie Pompeiu (C. R. Acad. Sci. Paris **188**) asserts that every set of positive measure has the property. The argument is flawed.
- **1944.** L. Chakalov (Tchakaloff) exhibits the disk as a counterexample, using $J_1$ zeros.
- **1973.** Brown, Schreiber and Taylor prove the spectral-synthesis criterion above and deduce that any bounded domain whose boundary has a **corner** (a point where $\partial\Omega$ is not $C^1$, in a suitable cone sense) has the Pompeiu property. Every polygon, cube, simplex therefore has it.
- **1976, 1981.** S. A. Williams establishes the equivalence with Schiffer's problem and proves that a Lipschitz domain failing Pompeiu has **real-analytic** boundary, and that $\partial\Omega$ then satisfies an analytic free-boundary condition.
- **1980s.** Berenstein; Berenstein–Yang; Aviles obtain the first genuine symmetry theorems under eigenvalue-multiplicity or curvature hypotheses. Berenstein–Gay develop the local Pompeiu problem.
- **1990s–2000s.** Garofalo–Segàla (conformal mapping and asymptotics of Fourier integrals), Ebenfelt (Schwarz function / analytic continuation of the Cauchy problem), Volchkov (convolution equations, symmetric spaces). Zalcman's bibliographic surveys (1992, 2001) remain the standard entry points.
- **2000s–present.** Counterexamples in non-Euclidean settings (Shklover) and nontrivial extremal domains for related overdetermined problems (Sicbaldi 2010) sharpen how much the Euclidean structure is doing.

The conjecture is open in every dimension $n \ge 2$.

## 4. Partial Results / Verified Cases

Proven cases — $\Omega$ must be a ball (equivalently, the set has the Pompeiu property) when:

- **Corners.** $\partial\Omega$ fails to be $C^1$ at a point: polygons, polyhedra, cones, cylinders with edges (Brown–Schreiber–Taylor 1973).
- **Non-analytic boundary.** Any Lipschitz $\Omega$ with $\partial\Omega$ not real-analytic (Williams 1976, 1981). This removes all $C^\infty$-but-not-$C^\omega$ domains.
- **Low multiplicity.** Berenstein (1980): if the frequency $\alpha^2$ arising in Schiffer's problem is a Dirichlet eigenvalue of $\Omega$ of multiplicity $\le n$, then $\Omega$ is a ball. In particular the case where $\alpha^2$ is the **first** Dirichlet eigenvalue (multiplicity 1, $u > 0$) yields to moving planes.
- **Curvature hypotheses.** Aviles (1986): symmetry holds for domains whose analytic boundary satisfies mean-curvature/convexity-type constraints derived from the free-boundary equation.
- **Planar special classes.** Garofalo–Segàla (1994) prove the conjecture for simply connected planar domains whose Riemann map satisfies explicit coefficient/curvature constraints; Ebenfelt (1993) settles it for planar domains whose Schwarz function continues meromorphically (quadrature domains), and for ellipses.
- **Two-radius / multi-radius data.** Delsarte's theorem: any pair of balls with radius ratio outside the countable exceptional set $\{j_{n/2,k}/j_{n/2,l}\}$ has the Pompeiu property jointly.

**Negative results elsewhere.** On the round sphere $S^n$ and in flat tori the Schiffer-type overdetermined problem has non-spherical solutions: Shklover (2000) built them from **isoparametric hypersurfaces**, and Sicbaldi (2010) produced nontrivial extremal domains for $\lambda_1$ in flat tori. Any proof of the Euclidean conjecture must use a feature these settings lack.

## 5. Principal Obstacles

- **No sign, no maximum principle.** For $\alpha^2$ beyond $\lambda_1$, $u$ oscillates. Moving planes, Weinberger's integral identity and Alexandrov reflection all need $u$ of one sign or a $P$-function with a definite sign; both fail. This is the single largest barrier.
- **Non-local, non-perturbative constraint.** Failing Pompeiu means $\widehat{\chi_\Omega}$ vanishes on an entire complex quadric $\Sigma_\alpha$ — an infinite family of conditions with no finite reduction. Perturbing $\Omega$ off a ball changes the zero set of an entire function of several complex variables in a way current techniques cannot track: the linearized problem at the ball is degenerate, with kernel generated by translations, so the implicit function theorem gives no local rigidity.
- **Analyticity is not enough.** Williams reduces to real-analytic $\partial\Omega$, then the condition becomes a nonlinear analytic Cauchy problem on $\partial\Omega$; Cauchy–Kovalevskaya gives local solutions freely. The obstruction is global (single-valuedness / closure of the boundary curve), and no known invariant detects it.
- **Bessel asymptotics degenerate.** Stationary-phase expansions of $\widehat{\chi_\Omega}(\alpha\theta)$ as $\alpha \to \infty$ encode boundary curvature; requiring vanishing for **one** fixed $\alpha$ discards the asymptotic regime where these expansions are sharp.
- **Space-form counterexamples.** Since analogues fail on $S^n$ and on tori, any purely local or purely spectral argument is doomed: the proof must invoke the Euclidean structure (flatness plus non-compactness plus the full $M(n)$-action) essentially.

## 6. The Gap

Everything proven either (a) rules out failure by a *boundary regularity* defect (corners, non-analyticity), or (b) assumes extra spectral/geometric data (low eigenvalue multiplicity, curvature signs, meromorphic Schwarz function). The open region is precisely:

> a bounded simply connected $\Omega \subset \mathbb{R}^n$ with **real-analytic** boundary, non-spherical, admitting a Neumann eigenfunction of **high multiplicity** frequency $\alpha^2$ that is constant on $\partial\Omega$.

The missing step is a rigidity mechanism for sign-changing solutions of $\Delta u + \alpha^2 u = 0$ under the doubly overdetermined boundary data — a substitute for the maximum principle. Equivalently: prove that the entire function $\widehat{\chi_\Omega}$ cannot vanish on a whole quadric $\Sigma_\alpha$ unless $\widehat{\chi_\Omega}$ is radial.

## 7. Current Research (as of June 2026)

- **Overdetermined-problem school** (Italy/Spain/France: Sicbaldi, Ros, Ruiz, Magnanini, Cavallina and collaborators). Bifurcation and perturbation constructions for overdetermined elliptic problems, mapping out exactly which ambient geometries admit non-spherical solutions, and hence isolating what Euclidean space forbids.
- **Quadrature domains / Schwarz function** (Ebenfelt, Khavinson, Lundberg and successors). Free-boundary and analytic-continuation methods; strongest leverage in $n=2$.
- **Convolution-equation and harmonic-analysis approach** (Volchkov school). Local Pompeiu problems, minimal-radius theorems, and extensions to symmetric spaces and the Heisenberg group; sharp two-radius results.
- **Spectral-geometry angle.** Nodal-set and eigenfunction-concentration methods applied to the constant-on-boundary condition; still exploratory.
- *(frontier — verify)* A. G. Ramm has posted successive preprints claiming a full proof of the Pompeiu/Schiffer conjecture over the past two decades. These have not been accepted by the community and contain steps repeatedly disputed by referees; treat as unresolved.

## 8. Future Work

- Build a **$P$-function or integral identity valid for sign-changing** $u$, perhaps weighted by $|\nabla u|^2 + \alpha^2 u^2$, to recover a Serrin-type rigidity.
- Settle $n=2$ **completely** using the conformal map $\varphi: \mathbb{D} \to \Omega$: the condition becomes a nonlinear equation on the Taylor coefficients of $\varphi$; proving $\varphi$ must be affine is a concrete, purely function-theoretic target.
- Determine whether **simple connectivity is necessary**: either produce a non-simply-connected Euclidean counterexample or prove the topological hypothesis is superfluous.
- Classify the **exceptional frequency set**: bound the multiplicity of $\alpha^2$, since Berenstein's theorem closes the problem once multiplicity $\le n$ is forced.
- Transfer Shklover's isoparametric construction backwards: characterize which structure of $S^n$ enables it, and prove that structure is absent in $\mathbb{R}^n$.

## 10. Worked Example / Concrete Special Case

**The disk fails the Pompeiu property — explicitly.** Work in $\mathbb{R}^2$, $K = \overline{D(0,r)}$.

*Step 1 — the transform.* For $|\xi| = \alpha$,
$$\widehat{\chi_{D(0,r)}}(\xi) = \int_{D(0,r)} e^{-i\langle x,\xi\rangle}dx = 2\pi\int_0^r J_0(\alpha s)\, s\,ds = \frac{2\pi r}{\alpha}J_1(\alpha r),$$
using $\int_0^{2\pi} e^{-i\alpha s\cos\theta}d\theta = 2\pi J_0(\alpha s)$ and $\int_0^t J_0(u)u\,du = t J_1(t)$.

*Step 2 — choose the frequency.* Let $j_{1,1} = 3.831705\ldots$ be the first positive zero of $J_1$, and set $\alpha = j_{1,1}/r$. Then $\widehat{\chi_{D(0,r)}}$ vanishes on the whole circle $|\xi| = \alpha$.

*Step 3 — the test function.* Put $f(x) = \cos(\alpha x_1)$, a nonzero real-analytic function. For any rigid motion $\sigma$, $\sigma(K) = D(a,r)$ for some $a$, and with $\xi = (\alpha,0)$,
$$\int_{D(a,r)} e^{i\langle \xi,x\rangle}dx = e^{i\langle \xi,a\rangle}\int_{D(0,r)}e^{i\langle\xi,y\rangle}dy = e^{i\langle\xi,a\rangle}\cdot\frac{2\pi r}{\alpha}J_1(\alpha r) = 0 .$$
Taking real parts, $\int_{\sigma(K)} \cos(\alpha x_1)\,dx = 0$ for every rigid motion. The disk fails.

*Step 4 — the Schiffer side.* Set $u(x) = J_0(\alpha|x|)$ on $D(0,r)$. Then $\Delta u + \alpha^2 u = 0$; on $|x|=r$,
$$u = J_0(j_{1,1}) = -0.402759\ldots \ (\text{constant}), \qquad \frac{\partial u}{\partial \nu} = \alpha J_0'(\alpha r) = -\alpha J_1(j_{1,1}) = 0 .$$
So $\alpha^2 = (j_{1,1}/r)^2$ is a Neumann eigenvalue whose eigenfunction is constant on the boundary — exactly the overdetermined data of Section 2.

*Step 5 — what the conjecture claims.* Repeat Step 1 for a non-circular domain, e.g. the ellipse $x_1^2/a^2 + x_2^2/b^2 \le 1$ with $a \ne b$. Then $\widehat{\chi_\Omega}(\xi) = 2\pi ab\, J_1(\rho(\xi))/\rho(\xi)$ with $\rho(\xi) = \sqrt{a^2\xi_1^2 + b^2\xi_2^2}$. On the circle $|\xi| = \alpha$, $\rho$ ranges over the full interval $[b\alpha, a\alpha]$, which has positive length; $J_1$ has only isolated zeros, so $\widehat{\chi_\Omega}$ cannot vanish identically there. The ellipse has the Pompeiu property. The conjecture says every non-ball behaves like the ellipse — but for a general analytic $\partial\Omega$ there is no closed form for $\widehat{\chi_\Omega}$, and that is the whole difficulty.
